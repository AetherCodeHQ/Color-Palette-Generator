## Installation

```bash
# Clone
git clone https://github.com/AetherCodeHQ/Color-Palette-Generator.git
cd Color-Palette-Generator

# Build
go build -o color-palette-generator .

# Run
./color-palette-generator [file]
```

### Or directly with `go run`:
```bash
go run main.go [file]
```
